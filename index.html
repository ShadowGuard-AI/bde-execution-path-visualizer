bde-execution-path-visualizer

The sorting table read from the incoming end to the bagging end. The penny post took every letter from its place of origin and sent it onward under one mark. This tool takes call shaped names from a script and lists each one outward from a single MainScript node, names, keywords, and all.

List the Names Beautify First Decode Strings Rename Variables

Read, Never Run

The script being listed is read as text and is never run. That is said first and plainly, because a visitor who fears the tool executes unknown code should be answered before any other fact.

A Flat List From MainScript

The output is a Graphviz dot file listing the call shaped names found in a script, as a flat list of edges from one MainScript node.

No Branches Are Drawn

There is no branching or control flow structure in the output. The name matcher also picks up keywords, so words such as if and for appear in the list as if they were calls. No function definitions, conditions, or branch targets are represented. A visitor who came expecting a drawn path through a program leaves knowing the file is a flat list, and this panel says so at reading size, not in a footnote.

The Three Passes

Beautify First

jsbeautifier formatting under --beautify, run before listing.

Decode Strings

String decoding under --decode_strings, covering base64 in the Python b'...' literal shape, and hex only inside a quoted 0x literal such as '0x41'. Numeric literals outside quotes are left alone, and the source example 0x10 is the case that is not touched.

Rename Variables

Variable renaming under --rename_variables. The opening account describes it as renaming underscore variables, and the parameter list describes it as an attempt to rename obfuscated variables. Both wordings are kept, because the source uses both.

Verbose logging under -v belongs on this row as a reporting switch, not a pass.

Bagging End: Getting It and Calling It

git clone https://github.com/ShadowStrikeHQ/bde-execution-path-visualizer

The install line is exactly as written. Beside it, a short note: the clone names ShadowStrikeHQ while this repository lives under ShadowGuard-AI.

./bde-execution-path-visualizer [params]
-hShow help message and exit
-vEnable verbose logging
--beautifyBeautify the input script before analysis.
--decode_stringsAttempt to decode encoded strings: base64 in the Python b'...' literal shape, and hex only inside a quoted 0x literal such as '0x41'. Numeric literals such as 0x10 outside quotes are left alone.
--rename_variablesAttempt to rename obfuscated variables.

The Unexplained Switch

-oNo description provided. This page will not guess that it names the output dot file, however likely that guess feels.

One further absence is stated on this panel: the parameter list names no input script argument, even though the tool works on a script, so how the script is handed to the program is not spelled out in the source.
