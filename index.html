bde-execution-path-visualizer

The Maypole Ring. A command line tool that writes a Graphviz dot file listing the call shaped names found in a script, every one of them a straight line out from a single MainScript node. No ribbon branches, and none are drawn.

The repository main.py
OutputA Graphviz dot file listing the call shaped names found in a script
ShapeA flat list of edges from one MainScript node
Optional stepsjsbeautifier formatting, string decoding, and renaming underscore variables before listing
The listed scriptRead as text and never run

OptionWhat the README records

--decode_stringsAttempt to decode encoded strings: base64 in the Python b'...' literal shape, and hex only inside a quoted 0x literal such as '0x41'.
--rename_variablesAttempt to rename obfuscated variables (renaming underscore variables).
-hShow help message and exit.

Stated limits

  • There is no branching or control flow structure in the output, and no function definitions, conditions, or branch targets are represented.
  • The name matcher also picks up keywords, so words such as if and for appear in the list as if they were calls.
  • String decoding covers base64 in the Python b'...' literal shape, and hex only inside a quoted 0x literal such as '0x41'; numeric literals outside quotes are left alone.
  • The script being listed is read as text and never run.
  • -o is listed with no description provided, and no purpose is guessed for it here.
